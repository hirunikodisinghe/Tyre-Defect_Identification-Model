# Tire Defect Identification Model

An AI-based tyre defect classification system developed using PyTorch and EfficientNet-B0.

The model identifies 12 tyre conditions from tyre images and provides prediction confidence, uncertainty information, and Grad-CAM based explainability.

## Supported Classes

- Abnormal Wear
- Bead Damage
- Bulge
- Cut
- Shoulder Crack
- Sidewall Crack
- Sidewall Damage
- Tire Burst
- Tread Chunking
- Tread Damage
- Tread Separation
- No Defect

## Technologies

- Python
- PyTorch
- Torchvision
- EfficientNet-B0
- OpenCV
- NumPy
- Pillow
- Grad-CAM
- Flask
- Waitress

## Main Features

- 12-class tyre defect classification
- Prediction confidence
- Top prediction analysis
- Uncertainty evaluation
- Grad-CAM explainable AI
- Image quality assessment
- Flask API deployment
- Human review support
